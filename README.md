# HTML 핵심 개념 실습

코드잇 스프린트 풀스택 이론 수업 **3. HTML 핵심 개념**(3h) 실습 코드입니다.
주제는 가상의 동네 책방 '숲속 책방'입니다.

## 사용 방법

1. `Code → Download ZIP`으로 받거나 `git clone` 합니다.
2. VS Code에서 **Open Folder**로 폴더째 엽니다.
3. 챕터 폴더의 `index.html`을 열고 head 안의 **연습 요구사항** 주석대로 body를 채웁니다.
4. VS Code 확장 **Live Preview**(Microsoft) 또는 Live Server로 열어서 확인합니다.
5. 먼저 직접 풀어 보고 막히면 같은 폴더의 `solution.html`(모범답안)과 비교하세요.

## 폴더 구성 (폴더 번호 = 노션 교안 대단원 번호)

| 폴더                 | 노션                   | 연습 내용                                                    |
| -------------------- | ---------------------- | ------------------------------------------------------------ |
| `001_html_intro/`    | [1] HTML이란?          | header · main · article · footer 뼈대, 코멘트                |
| `002_links/`         | [2] 링크               | 절대·상대 주소, #아이디 이동, 새 창, mailto, tel             |
| `003_text/`          | [3] 텍스트             | h1~h2 · p · strong · em · blockquote · code · pre · br       |
| `004_lists/`         | [4] 리스트             | ol · ul · li · dl/dt/dd                                      |
| `005_tables/`        | [5] 테이블             | caption · thead · tbody · tfoot · th · colspan               |
| `006_multimedia/`    | [6] 멀티미디어         | img · figure · video · audio                                 |
| `007_forms/`         | [7] 폼                 | form · label · input · select · textarea · button            |
| `008_external_code/` | [8] 다른 코드 불러오기 | link(CSS·파비콘) · script(defer·async)                       |
| `009_semantic/`      | [9] 시맨틱 HTML TAG    | meta description · og · header · nav · main · aside · footer |

수업 시간에 다 못 푼 연습은 복습용입니다. 10/6~7 (실기) HTML 핵심 개념 시간에 이어서 씁니다.
